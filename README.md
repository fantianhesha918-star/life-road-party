# アニマルライフ(旧ライフロード)

人生ゲーム風のマルチプレイすごろくアプリ。盤面・カード・ルールはすべてオリジナル(市販の「人生ゲーム」の商標・盤面は使用していない)。リポジトリ名・公開URLは旧名称`life-road-party`のまま据え置いている(アプリ内表示名のみ「アニマルライフ」に変更)。

- 公開URL: https://fantianhesha918-star.github.io/life-road-party/
- 公開元フォルダ: `docs/`(GitHub Pages)
- ビルド不要。`docs/`配下を直接編集して`git push`すれば反映される。
- Firebaseプロジェクト: `life-road-party`(Firestore + 匿名認証、リージョン`asia-northeast1`)

## 現在の状態(2026-08-11時点)

- 一人モード(CPU対戦)・通信モード(部屋番号で友達と接続、CPU混在も可)ともに動作確認済み。
- Firestoreセキュリティルール(`firestore.rules`)は、本番のFirebaseプロジェクトに対するREST APIテスト(部屋作成・参加・不正書き込み拒否・手番制御・ハートビートの8パターン)と、実機(スマホ2端末)での通信対戦の両方で動作確認済み(2026-08-03)。
- **TTLポリシー(部屋の自動削除)は見送り**: TTL機能の利用にはBlazeプラン(課金プラン、要クレジットカード登録)への切り替えが必須という仕様のため、無料枠のみで運用する方針上、Sparkプランのまま据え置いている。放置データが気になる場合はFirestoreコンソールから手動削除できる。
- **盤面の3D化(フェーズC)が完了し、本番のプレイ画面に統合済み**(2026-08-09)。2Dの横スクロール盤面は廃止し、Three.js製の3D盤面(曲がり道+奥にフォグがかかる世界観)に一本化した。プレイヤーキャラクター8種すべて・マップ装飾(建物/施設/木/街灯/ベンチ/看板/スタートゴールゲート/雲/空/地面/道/橋/マス種別アイコン/結婚マスの教会と新郎新婦)が実3Dモデルで表示される。詳細下記。
- **株・保険・マイホーム・結婚/出産などの追加ギミックを実装済み**(2026-08-09)。詳細下記。
- **通信モードへのCPU混在に対応済み**(2026-08-11): 部屋作成時にCPUの人数を指定でき、CPUの手番はホストのブラウザが代行して進行する。
- **マス数モードを拡張済み**: 30マス固定から、短い(100マス)・普通(200マス)・長い(300マス)の3モードに変更(`game-data.js`の`GAME_MODES`)。

## アバター・コイン・ショップ機能

- プレイヤープロフィール(コイン・所持アイテム・装備中の動物種/色/帽子/アクセサリー・消耗品の所持数)は**端末のlocalStorageにのみ保存**(Firebaseには送らない)。各プレイヤーは自分のスマホで遊ぶ想定のため、端末ごとにコイン・アイテムが独立して蓄積されていく。
- 対局終了時、最終所持金に応じてコインを獲得する(10万円につき1コイン、`shop-data.js`の`GAME_REWARD_MONEY_PER_COIN`で調整可能)。
- 獲得コインでショップ(色・帽子・アクセサリー・消耗品)を購入し、キャラクター編集画面で装備できる。
- **キャラクターの種類**: 動物6種(チンチラ グレー・白パイド、いぬ フレンチブルドッグ白・黒、ねこ 三毛猫、うさぎ 白・座りポーズ)+にんげん2種(男の子・女の子)の計8種から選べる(`shop-data.js`の`SPECIES_ITEMS`)。全種すべて最初から無料で所持・切替え可能。実イラスト(`docs/avatars/`)・実3Dモデル(`docs/models/`)とも整備済み。動物6種は正面顔アップの写実的なポートレート様式、にんげん2種はトイフィギュア調と、意図的にテイストを分けている。動物6種には性別も設定されている(オス:チンチラグレー・フレブル白・フレブル黒/メス:チンチラ白パイド・三毛猫・うさぎ)。
- **コスチューム(全身衣装)を5種類、6キャラクターぶんイラスト化済み**(着物・スーツ・忍者・くまの着ぐるみ・ウェディング衣装[性別でタキシード/ドレスを分けたデザイン])。**3Dモデル化・ゲームへの組み込みは着物×チンチラ(グレー)の試作1件のみ完了**(`COSTUME_MODEL_MAP`、他の組み合わせは3D盤面には未反映でショップ・キャラクター編集画面のイラストのみ反映)。ウェディング衣装は2体(チンチラ グレー/白パイド)のみ、プレイヤーの着せ替えではなく結婚マス周辺の風景装飾として3D化・組み込み済み。
- 通信モードでは、部屋を作成/参加する瞬間の「装備中の見た目」だけを部屋データに含めて送るため、コイン・所持アイテム自体は非公開のまま、対戦相手にはコスチュームだけが見える。

## ターン進行(ルーレット・ターンハブ・消耗品)

- サイコロ(1〜6)を廃止し、ルーレット(1〜10のランダム)に変更した(`game-engine.js`の`rollDice()`)。
- 自分の手番になると、アバターがポップインするターンハブ画面が表示され、「ルーレットを回す」「アイテムを使う」「ステータスを見る」の3択から選べる。ルーレットを回すと1〜10の数字が連続表示されるスピン演出のあと出目が確定する。
- 「アイテムを使う」では、ショップで購入した消耗品(臨時収入チケット・幸運のお守り・節税シールなど)を使って即座に所持金を増やせる(手番は終了しない)。消耗品はコスメアイテムと違い何個でも購入・重複所持できる。
- 盤面は3D空間として表示され、手番プレイヤーがルーレットの出目ぶんマスをひとつずつホップ移動するアニメーションに合わせてカメラが追従する。通信モードでは、この演出は「自分の手番を自分の画面で見ているとき」だけ再生され、相手の手番の移動は最終確定後の位置のみ相手側の画面に反映される(Firestoreは最終状態のみを同期するため)。

## マス目イベント・追加ギミック(2026-08-09実装)

- マス数(100/200/300)に応じて盤面を自動生成し、各マスのイベント内容(`eventCardIndex`/`fortuneCardIndex`/`choiceEventIndex`)を割り当てる(`game-data.js`)。イベントカード28件・運のカード14件・選択イベント9件を使い回す。
- **結婚マス(強制停止)**: 止まったプレイヤーが他の全プレイヤーからお祝い金を受け取る。
- **子どもが生まれるマス(着地時のみ)**: 授かりものとしてお祝い金を支払う。
- **株システム**: 4箇所のトリガーマスを通過するたびに購入選択(10株/-30万円、売却なし・上限なし)。保有中は通過のたびに値上がり/値下がりイベントで所持金が増減。
- **マイホーム**: 6段階の価格帯から購入(最高額のタワーマンションのみ早い者勝ちの排他制)。火災マスで家が焼失(火災保険加入者は70%を保険金として受け取れる)。家の交換マスもあり。
- **清算(全員ゴール後)**: 子ども・保有株・マイホーム・ゴール到達順に応じたボーナスを所持金に加算し、最終順位を決定。
- **ひと休みマス**: 自分の次の手番を1回スキップ(2人プレイでの手詰まり防止策あり)。

## CPU AIの性格プリセット

- 一人モードのCPUプレイヤーには、ゲーム開始時に3種類の性格プリセットからランダムで1つ割り当てられる(`cpu.js`の`CPU_PERSONALITIES`)。プレイヤーリストに「CPU1(CPU・野心家)」のように表示される。
  - 野心家: 就職の選択肢のうち給料が高い方を選ぶ(従来のCPU挙動と同じ)
  - 堅実家: 給料が控えめな方を選ぶ
  - 気まぐれ屋: ランダムに選ぶ
- 現状、性格が影響するのは就職の選択のみ(株・保険・マイホーム購入などの意思決定には未反映)。
- 一人モード・通信モードのCPU混在どちらにも適用される(通信モードではホストのブラウザがCPUの手番を代行して進行する)。

## 盤面の3D化(フェーズC完了・本番統合済み)

- Three.js(CDN経由、ビルド不要)+ Meshy AI(有料プラン)で生成した低ポリキャラクター・装飾モデルを使用。世界観は「曲がり道+奥にフォグがかかる」方式(壁で囲むジオラマ方式は不採用)。
- プレイヤーキャラクター8種(動物6種+にんげん2種)すべて、マップ装飾一式(建物・施設・木・街灯/ベンチ/看板・スタート/ゴールゲート・雲・空/地面/道テクスチャ・テロップ枠/ルーレット盤面UI・橋・マス種別アイコン・結婚マスの教会と新郎新婦)を実3Dモデルで表示。建物はマスの種類(就職・給料日・イベント・お休みなど)に応じたテーマ付けもされている。詳細な生成経緯・ライセンスは`docs/models/CREDITS.md`参照。
